PREFIX ex: <http://example.org/>
SELECT ?title
WHERE {
  ?show  a              ex:Musical ;
         ex:hasPerformer ex:ArtistA ;
         ex:hasTitle     ?title .
}
PREFIX ex:‘ex:’를 긴 주소 http://example.org/ 의 줄임말로 쓰기

      -[:PERFORMS_IN]->(m:Musical)
