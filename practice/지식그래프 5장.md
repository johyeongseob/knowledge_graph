5. 지식그래프 활용을 위한 시스템 아키텍처
지식그래프는 현실 세계의 복잡한 개체들과 그들 사이의 관계를 구조화된 네트워크로 표현함으로써, 시스템이 '이해하고 연결'할 수 있도록 돕는 프레임워크이다. 이번 장에서는 지식그래프가 다양한 시스템에서 어떻게 사용되는지 각 시스템 아키텍처를 분야별로 살펴본다.

5.1. 지식그래프를 활용한 검색엔진
지식그래프 기반 검색엔진은 질의 속 개체와 관계를 이해하고, 이를 구조화된 지식망 위에서 탐색함으로써 보다 정확하고 의미 있는 정보를 제공한다.

1. 사용자 질의 입력 "2023년에 개정된 개인정보 관련 지침이 뭐야?"
2. 개체 및 관계 추출

- 개체 (Entity): "개인정보 지침", "2023년"
- 관계 (Relation): "개정", "시행"

3. 지식그래프 매칭 "개인정보 치침" - "개정일자", "개정일자 = 2023년"
4. 그래프 탐색 및 질의 수행: 매칭된 개체와 조건을 바탕으로, 지식그래프 내에서 관련 노드와 경로를 추론

```
MATCH
(policy: Guideline {title: "개인정보 지침", revisedYear: "2023"})-[:LINKED_DOCUMENT]->(doc)
RETURN doc
```

5. 관련 문서/데이터 검색:외부 데이터 소스와 연결된 경우, 해당 노드와 연결된 관련 문서, 보고서, 데이터 등을 함께 검색
6. 최종 응답 구성 및 시각화: 사용자의 질의와 연결된 개체들 간의 관계망을 시각화하여 함께 표시

```
[정책명] 개인정보 보호 지침
[개정 연도] 2023
[시행일자] 2023-03-01
[소관 부서] 정책기획팀
[문서 ID] doc_423
```

5.2. RAG
RAG (Retrieval-Augmented Generation)는 LLM과 외부 지식 소스를 결합해 응답을 생성하는 구조이다. 사용자가 질문하면, LLM이 외부에서 관련 정보를 검색해 온 뒤, 그 정보를 바탕으로 신뢰할 수 있는 응답을 생성하는 방식이다.

1. 사용자 질의 입력 "톰 행크스가 출연한 SF 영화는?"
2. 검색 단계
2.1. Vector Search: 기존의 문서에서 의미 유사성을 기반으로 검색
2.2. Graph Search: 지식 그래프 내에서 '톰 행크스" 노드를 기준으로 탐색
3. 정보 결합 및 LLM 입력: 추출된 정보들을 조합하여 LLM에게 전다
4. 지식 기반 응답 생성: 단순한 "언어 생성"이 아닌, 질문과 연결된 정확하고 설명 가능한 응답을 생성

5.3. 추천시스템에서의 지식그래프
지식그래프 기반 추천 시스템은 플랫폼에서 상품과 사용자 간의 관계를 구조화하고, 이를 바탕으로 더욱 정확하고 설명력 있는 추천을 가능하게 한다.

1. 지식그래프 구축: 플랫폼에서 사용자와 관련된 정보들을 수집하여 노드로 정의하고, 이들 간의 관계를 엣질로 구성해 그래프를 만든다.

```
<사용자 A, 조회 상품 X>
<상품 X, 속성, 러닝화>
<사용자 A, 팔로우, 사용자 B>
```

2. 지식그래프 임베딩: 각 노드와 관계를 정보가 압축된 저차원의 밀집 벡터로 변환한다. 유사한 의미를 가진 노드끼리는 유사한 벡터인 숫자로 표현되며, 기계학습 모델이 이를 활용해 관계성을 학습한다.
3. 협업 필터링 및 유사도 추론: 행동 이력과 지식그래프에서 얻은 의미 기반의 관계 정보를 통해 유사도를 계산한다.
4. 추천 예측 모듈: 후보 Top-N 아이템들 중에서 실제로 얼마나 좋아할 가능성이 있는지, 또는 어떤 순서로 추천할지를 정하는 과정이다.
