2. 지식그래프의 활용

지식그래프는 다양한 산업 분야에서 의사결정과 자동화의 엔진으로 주목받음
-> 실제 활용 사례를 살펴보자.

2.1. Google: 새로운 검색 엔진의 시작
검색 엔진은 데이터의 바다 속에서 사용자가 원하는 정보를 정확하고 신속하게 찾는 것을 도와준다.

초기 검색엔진: 키워드 기반 검색 방식

1. TF-IDF (Term Frequency-Inverse Document Frequency)
   "특정 문서 안에서 자주 나오면서(TF), 다른 문서 전체에서는 드물게 나오는(IDF) 단어가 진짜 중요한 단어다"라는 개념을 수치화한 가중치 모델
   TF × IDF를 계산하여, 흔한 단어는 걸러내고 그 문서만의 핵심 키워드를 가진 문서를 상위에 노출

2. BM25 (Best Matching 25)
   TF-IDF의 한계: 특정 단어가 일정 횟수 이상 나오면 관련성은 사실상 비슷하지만 점수가 높음
   보완: 단어가 아무리 많이 나와도 점수가 무한정 오르지 않고 특정 한계치에 수렴(포화)하도록 설계
   문서 길이 정규화: 문서의 전체 길이를 고려하여, 짧은 문서에 검색어가 집중되어 있을 때 더 높은 점수를 부여

3. PageRank
   구글(Google)의 창업자들이 개발한 '웹페이지 간의 인맥 관계(링크)'를 분석하는 알고리즘
   인사이트: 학술 논문 인용 방식 차용처럼, 좋은 웹페이지일수록 다른 웹페이지로부터 링크(하이퍼링크)를 많이 받을 것이라는 가정

기존 방식의 단점: 의미 파악의 부재, 사용자 의도 미반영, 정보 연결 부족

2.1.1. Google의 지식그래프 기반 검색
구글은 검색엔진에 지식그래프를 도입하면서 검색 서비스의 품질을 향상

2.1.2. 구글의 지식그래프 기반 검색의 핵심 기능

- 지식그래프 패널: 검색 단어와 관련된 다양한 정보가 구조화된 요약 형태로 제공
- 요약 정보 제공: 검색어의 주요 정보와 연관 맥락을 통합적으로 요약 및 제공
- 관련 정보 연결: 검색어와 관련된 객체들과의 관계도 시각화

2.2. Amazon: 당신의 취향을 연결하다
추천 시스템: 사용자의 행동이나 관심사에 따라 맞춤형으로 정보를 제공하는 것
-> 전자상개래 플랫폼의 핵심 기능

전통적인 추천 알고리즘

- 연관 분석: A 상품을 구매한 고객은 B 상품도 구매했다 의 규칙을 도출하여 추천
- 협업 필터링: 유사한 행동을 보이는 사용자들의 데이터를 기반으로 추천
- SVD 기반 잠재요인 모델: 사용자-상품 간 상호작용 행렬을 분해하여 숨겨진 선호도를 수치화 및 추천

한계점: 설명 가능성 부족, 콜드 스타트 문제, 의미 기반 연결 부족, 속성 정보 활용 미흡

2.2.1. 추천시스템에서의 지식그래프 활용
지식그래프 기반 추천 시스템의 작동 과정

1. 사용자 행동 이력 수집: 사용자의 선호도를 파악하는 핵심 역할
2. 지식그래프 연동 및 개체 추출
3. 의미 기반 탐색 및 확장: 사용자의 관심 객체와 의미적으로 연결된 노드들을 확장 -> 추천 후보군에 들어감
4. 후보군 생성 및 랭킹: 연결 경로의 강도, 유사도, 노출 빈도, 사용자 피드백 등을 고려하여 우선순위 정렬
5. 추천 결과 제공 및 설명

2.3. Intuit: 보이지 않는 위험까지 관리하다
지식그래프는 보안 위협 대응과 사기 탐지 분야에서 핵심 기술로 사용

전통적인 보안 및 사기 탐지 방법

- 규칙 기반 시스템: 전문가가 정의한 규칙에 따라 이상 거래를 탐지하는 방식
- 통계적 이상 탐지: 평소 거래 패턴에서 벗어나는 거래를 이상으로 간주
- 머신러닝 기반 탐지: 지도학습 방식으로 사기 패턴을 예측

한계: 주로 정적인 규칙이나 수치 기반 패턴에 의존하여 행위 간의 숨은 의미나 관계성을 찾기 어려움
보완: 지식그래프를 이용하여 다양한 요소들을 하나의 그래프 위에서 관계 중심으로 구조화

2.3.1.Intuit 보안 지식 플랫폼
Intuit는 기존 보안 시스템을 보안 관련 entity 간의 관계 중심 분석으로 전환

2.3.2. Intuit 보안 지식 플랫폼의 시스템 작동 방식

- 로그 수집 밎 실시작 삽입: 로그인 기록, 접속 위치, 디바이스 정보 등을 수집하여 그래프에 연결
- 관계 기반 위협 탐지: 평소와 다른 IP나 디바이스로 접속했는지, 의심스러운 거래와 연계되는 계정 탐지
- 시각화 및 패턴 인식: 시각화 툴을 통해 위협의 연결망을 탐색

2.4. 팔란티어: 산재된 지식을 전략으로
지식그래프를 활용하면 조직 내의 산재한 데이터를 하나의 구조 속에서 통합하고, 이를 다양한 방식으로 활용할 수 있는 전략 정보 시스템을 만들 수 있다.
작동 방식

1. 데이터 수집: 기업 데이터 소스를 수집
2. 온톨로지 정렬: 옽톨로지를 통해 수집된 데이터를 구조화하고 분류
3. 정보 추출: 데이터에서 중요한 정보들을 추출하여 그래프 생성
4. 그래프 완성 및 추론: 생성된 그래프에 대한 잠재적 개체와 관계를 예측하여 완전 그래프를 구현
5. 활용: 그래프를 활용하여 다양한 지능형 서비스로 활용

-> 데이터를 존재하는 것이 아닌 기업 전략 수립과 의사결정의 기반이 되는 자산으로 전환

2.4.1. 지식그래프 기반의 전략 시스템 사례

팔란티어는 온톨로지와 지식그래프 기반의 데이터 플랫폼을 통해, 실시간 통찰을 제공하는 전략 시스템을 구현
데이터를 의미 있는 구조와 속성, 그리고 관계를 정의한 뒤, 이를 일관된 구조로 통합

2.4.2. 팔란티어의 의사결정 시스템 핵심 구성 요소

1. 고담 (Gotham): 작전/첩보 플랫폼. 데이터를 구조화한 후, 테러범위 위치, 인신매매 경로, 금융 사기의 네트워크를 시각화 및 추론
2. 파운드리 (Foundry): 기업용 데이터 통합 플랫폼. 재무, 인사, 물류, 재고 데이터를 하나의 온톨로지 프레임워크에 연결하여 협업이 가능 및 지연 이슈도 파악
3. 아폴로 (Apollo): 팔란티어의 다른 플랫폼 (고담, 파운드리 등)을 자동으로 업데이트하고 유지하는 SaaS 기반 플랫폼
4. AIP (AI Platform): LLM과 기업 내부 데이터를 연결하여 LLM이 온톨로지 기반 지식그래프를 활용해 정확한 분석을 도출
