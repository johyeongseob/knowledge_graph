지식그래프 AI와 온톨로지로 여는 지식혁명 - 이강배 외 3인

---

서문

데이터를 의미 기반으로 조직하고 연결하며, 이를 통해 실질적인 지식 기반의 의사결정을 수행 -> 지식 그래프 (Knowledge graph)

-> 수집한 방대한 데이터를 그리고 다양한 문서들을 '의미 있는 지식'으로 전환

---

1. 지식 그래프에 대하여

현재 방대한 데이터가 생성되고 유통된다. -> 이 중 어떻게 '가치'를 찾아낼까? -> 지식그래프를 통해 지식들을 통합, 구조화하며 새로운 지식을 추론 -> 비즈니스 가치로 연결

1.1. 지식그래프란 무엇일까?

지식그래프는 데이터를 개체\* (entity) 단위로 분해하고, 그들 사이의 관계 (relation)를 그래프 구조로 표현한 것

- 구성: 삼중항 (node-edge-node, 주체-관계-객체)
- 요소: 노드, 엣지, 속성, 라벨
  -> 지식그래프를 설계하고 규정하는 것이 온톨로지 (Ontology)

* 엔티티 (Entity, 개체): 현실 세계나 특정 도메인에 존재하는 독립적이고 식별 가능한 모든 '사물'이나 '개념'
  엔티티의 핵심 특징: 고유한 식별자(URI/IRI), 속성(Property)

지식그래프는 데이터 간 의미 있는 연결을 통해 새로운 가치를 창출하는 도구
-> 기계가 인간의 지식을 이해하고 학습하는 방법

1.2. 인공지능과 지식그래프의 역사

첫 번째: 인공지능은 지식을 이해하기 위해 기호 기반 (symbolic) 접근 방법을 사용
한계: 모든 규칙과 지식을 수동으로 정의하는 것
두 번째: 확률 기반 기계학습 (Connectionist) -> 신경망의 부상 -> 지식그래프는 마이너
세 번째: 시멘틱 웹 (Sementic Web) -> 증가하는 웹 데이터를 기계가 이해하고 처리할 수 있게 의미를 부여 -> RDF, OWL, SPARQL\*\*
네 번째: LLM과의 융합 -> LLM은 확률 기반 답변의 단점인 논리적 연결에 대한 보강
-> RAG를 사용하여 지식그래플 LLM의 기억 창고로 사용

** RDF (Resource Description Framework) - "데이터를 기록하는 기본 뼈대"
** OWL (Web Ontology Language) - "데이터의 의미와 관계를 정의하는 규칙 사전
\*\* SPARQL (SPARQL Protocol and RDF Query Language) - "지식그래프 전용 데이터 검색창"

1.3. 거대언어모형과 지식그래프
LLM 장점: 방대한 언어 데이터를 학습하여 사람처럼 자연어를 이해하고 생성
LLM 단점: 사실을 정확히 기억하지 못함, 지식의 구조를 이해하지 못함
-> 실무에서 LLM을 사용하기 위해서는 신뢰성, 설명 가능성, 법적 책임성 등 다양한 요건을 충족시켜야 함
-> 과제: 지식의 구조화, 검증 가능성, 설명 가능한 신뢰 기반의 시스템 구축

LLM과 지식 그래프 결합의 기대효과

- 사실 기반 응답 제공: 정확하고 신뢰할 수 있는 배경 지식을 제공
- 의미 기반 추론 강화: 그래프 속 인과관계를 통해 논리적 추론이 가능
- 용어의 모호성 해소: 용어를 정확한 맥락에 연결

  1.3.1. 지식그래프를 활용한 LLM 보완 방법

1. 지식그래프 강화 LLM (KG-enhanved LLMs)
   한계: LLM이 잘못된 정보를 생성
   보완: LLM을 사전 학습 시, 지식그래프 정보를 반영 혹은 실시간으로 구조화 지식을 참고

2. LLM 증강 지식그래프 (LLM-augmented KGs)
   한계: 지식그래프는 텍스트 외 정보에 취약하고 누력된 사실도 존재
   보완: LLM을 통해 텍스트에서 개체와 관계를 추출하거나 누락된 사실을 보완

3. 시너지 LLM + 지식그래프 (Synergized LLMs + KGs)
   사례: LLM과 지식그래프의 장점을 동시에 살림 -> AI가 더 정확하고, 설명 가능하며, 신뢰할 수 있음

1.3.2. 거대 언어 모델을 이용한 지식그래프 구축
방대한 텍스트 데이터를 학습한 LLM은 텍스트 내 의미와 구조를 이해하고, 내포된 지식까지도 효과적으로 추출 가능하다.
-> 이를 활용하여 지식그래프를 자동화된 방식으로 생성, 관리, 확장할 수 있음

1. 객체 및 관계 추출 (Entity and Relation Extraction)
   LLM은 텍스트 내에서 주요 개체를 식별하고, 개체들 사이의 관계를 파악 -> 지식그래프의 노드와 엣지를 자동으로 생성

2. 관계 분류 (Relation Classification)
   LLM은 문맥을 이해하여 다양한 관계 유형을 분류

3. 개체 연결 (Entity Linking)
   LLM이 주변 문맥을 고려하여 텍스트에 언급된 개체가 기존 지식그래프의 어떤 노드에 해당하는지 연결

4. 정보 추출 및 통합 (Information Extraction and Integration)
   다양한 텍스트 소스로부터 정보를 추출 및 일관된 지식그래프로 통합

1.3.3. 거대 언어 모델을 이용한 지식그래프 관리
LLM은 구축된 지식그래프를 관리하고 확장하는 데에도 효과적으로 활용할 수 있다.

1. 지식그래프 완성 (Knowledge graph completion)
   지식그래프에 누락된 정보를 LLM을 이용하여 추론, 예측하여 채울 수 있다.

2. 지식그래프 업데이트 (Knowledge Graph Update)
   새로운 정보를 지식그래프에 자동으로 업데이트

3. 지식그래프 품질 관리 (Knowledge Graph Quality Management)
   지식그래프 내의 오류나 불일치를 감지하고 수정
